# Common ZPL Commands

| Command | Purpose |
|---|---|
| `^XA` | Start a label format |
| `^XZ` | End a label format |
| `^PW` | Print width |
| `^LL` | Label length |
| `^FO` | Field origin |
| `^A0` | Scalable font 0 |
| `^FD` | Field data |
| `^FS` | End field |
| `^BY` | Barcode defaults |
| `^BC` | Code 128 |
| `^B3` | Code 39 |
| `^BU` | UPC-A |
| `^BQ` | QR code |

Full reference:
https://printenvoy.com/zpl-commands/
