# Testing ZPL

1. Confirm each label starts with `^XA` and ends with `^XZ`.
2. Check `^PW` and `^LL` against the target label size and DPI.
3. Review `^FO` coordinates.
4. Check barcode commands and data.
5. Preview in Print Envoy ZPL Visualizer:
   https://printenvoy.com/zpl-visualizer-tool/
6. Validate final output on the real production printer and media.
